# Student Attendance

A browser-based classroom attendance management tool.

## Features

- Student list
- Present and absent status
- Attendance summary

## How to Use

Add students and select their attendance status.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
## Manual Testing Checklist

- [ ] Add a student and set the attendance to Present.
- [ ] Change the status to Absent and review the summary.
- [ ] Remove the student and confirm the total updates.

### Test Notes

Record the observed result and any reproducible issue after running the tests.
